# 术语与辅助视角

## AI先锋与 OPT

下表保留 Randy 在该项目中的术语定位，不把它写成行业标准、外部作者定义或认证量表。

| 称呼 | 本项目含义 | 不能推导 |
| --- | --- | --- |
| AI先锋 | 善用 AI 并在实际问题中推进应用的能力／实践角色；包含组织内部推动者和帮助他人应用的人 | 必须成立一人公司、已有独立商业成功、一定是 OPT |
| OPT | AI先锋的一种落地：非常善用 AI 的高水平实践者，既有问题定义与判断，也能组织人与 Agent 协作；一个人带领一群 Agent 创造价值是具体实践形态 | 一般会用 AI、所有 AI先锋、OPC、已证明商业成功 |
| 潜在超级个体 | 有值得继续观察的实践 | 已证明的收入、规模或商业成功 |

Randy 在个人定位中将 OPT 对应为第9层／第10层的高阶实践。这里保留的是其个人对应，不能反向声称外部原文把 OPT 定义在这两层。本包只保留使用这一定义所需的说明，不附参考全文、图片或完整等级表。

不自行扩写 OPT 英文全称，不与 OPC 混用。AI先锋不必走向 OPT，称呼之间不是人人必经的线性阶梯；OPT 全球创业是观察方向之一，不是所有内容的必选分类。

## 写人物样本

先写可观察的实践：问题如何定义，人和 Agent 各做什么，有何产物，如何判断质量、处理失败、积累系统并跨领域学习。再决定是否需要称呼。

公开稿使用 OPT 须有对应实践证据，并注明这是本项目术语下的编辑判断。拿不准时仅描述实践；不能因工具、付费档位、Skill 数量、Agent 数量、收入或年龄单项认定能力等级。发布和人物资料使用仍须满足相应授权。

## 辅助提问，不作硬套理论

- 组织角色：这个人是在创造可复用工具、方法并赋能同事，还是在使用已有工具改善工作？两种角色都可有价值，不硬等同 OPT。
- 任务环境：问题能否沿用标准流程，是否需要专业分析、试探学习或紧急止损？不同任务需要不同工作方式。
- 成长与学习：经验失效时怎样发现问题、调整目标、接收反例和形成反馈？既看战略变化，也看日常标准化的适用条件。

这些只是提问视角，不对具体个人永久定级，不建立成长阶段与任务环境的一一映射，不引用未经测量的人群比例或成效倍数。
