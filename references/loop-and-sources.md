# 来源、反馈与学习复盘

本文件描述编辑规则和设计方向，不证明任何反馈功能、数据采集或学习算法已经部署。

## 来源与许可

公开国内外材料、获准访谈、产业交流、实践记录都可提供线索。非公开不等于更真或更高分；热度不等于价值；来源类型本身不加分。

| 许可状态 | 处理 |
| --- | --- |
| 公开材料 | 可在任务授权内研究；引用、转载和商用范围单独核对 |
| 仅获内部使用许可 | 只在该范围内部研究，不进公开稿；不得靠脱敏扩大许可 |
| 已获公开使用许可 | 仍核对事实、隐私与许可范围，公开发布另须动作授权 |
| 公开许可不明，但已获内部许可 | 仅内部研究，交任务负责人确认公开范围 |
| 内部使用许可也没有或不明 | 不使用，不评分、不摘录、不制作内部研究卡 |

个人与客户的私人资料、私下评价和身份不进公开稿。来源清单或技能说明不授权账号访问、抓取、联系或新增采集。

## 反馈解释

可研究点赞、负反馈、收藏、评论，但收到反馈材料不等于获得持续采集行为数据的许可。现有数据、字段、保留期限、异常升级和学习更新办法须据实际任务确认。

- 喜欢、有用、准备使用、不相关、可信度疑问分别理解；点赞不证明事实，收藏不等于已采用或取得效果。
- 编辑质量分、面向个人的相关性排序、学习用反馈信号分开。反馈不能覆盖来源核验或个人原分。
- 低曝光与少互动不等于低价值，避免信息茧房、热度偏差与刷量操纵；具体检测方法需要验证，不能声称已经有效。
- 评论中的反例、新证据和质疑先列待核；核实后再改事实、评分或分区，不凭评论数量判真伪。

## 纠正与复盘

记录原分与理由、原编辑判断、错误假设和窄的修正。不因用户喜欢就整体提分，不用单例擅自重写权重、门槛或计数；在后续未评分的获准材料上验证修正。

复盘时可以记录：

```text
条目｜原分区与分数｜触发（纠正／评论／新材料）｜新信息与核验状态｜改了什么与依据｜未改什么与原因｜计数是否迁移
```

这是说明用的最小记录格式，不是已上线产品字段或采集授权。

## 自主与升级

AI 负责常规筛选、整理反馈、优化来源与质量复盘；人负责产业连接、判断和一手经验。此方向不构成长期逐条审核要求，也不是自动发布许可。

以下情形交任务负责人处理：许可不明；涉及个人负面判断或隐私；与获准锚点明显冲突；核心事实受到质疑而无法核实；需要新的账号、联系人、采集或排程权限；任何发布或对外动作。

自主阈值、升级流程与时限、发布边界、反馈字段、学习更新办法和记录保留期限仍需单独设计与授权，不写成已存在的能力。
