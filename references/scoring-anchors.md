# 评分校准与个人原分

## 个人原分

本公开候选不附带任何人的私人评分清单、客户案例或个人影响记录。若具体任务另行提供已获准使用的锚点，原分、加号与理由原样记录；阅读权限不自动允许公开这些偏好。

- 85 与 85+、80 与 80+ 不互换，不把加号改成一个整数。
- 用户原分不证明事实，也不由编辑分替换。
- 未读锚点正文时，只比较任务提供的理由，不虚构内容或五维拆分。
- 个人影响与编辑质量分分开；没有锚点时照实写“未提供可用锚点”，不阻塞有依据的评估，也不编造原分。

## 合成对照

以下全部是虚构的校准说明，不是私人原分、实测效果或自动保底分。材料应有的得分仍由实际读取、受众相关性和证据决定，不能为接近示例改分。

| 合成情形 | 应如何判断 |
| --- | --- |
| 工厂自述改善但缺统计口径，编辑总分64 | 可内部观察，列核查项；点赞不改变证据分，不计每日合格条数 |
| 报价机制可读但结果待核，编辑总分69 | 内部观察，不因机制有趣就改称可计数的案例研究 |
| 具体案例72分，来源可追溯、机制有依据、复用条件仍待核 | 案例研究区，明确待核项，单独计研究数 |
| 已核验新闻75分，启发清楚且满足本次时间窗口 | 正式信号，计正式信号数 |
| 案例75分但结果主张待核，其他研究区条件满足 | 研究区；75不自动放行 |
| 82分线索却未取得核心事实证据 | 不正式，也不降成75以进入研究区；可内部观察并继续核查 |

完整分区与计数规则见 [scoring-rubric.md](scoring-rubric.md)。外部、未亲测、无短期 ROI 都不是固定上限；实际研究价值也不能绕过证据、许可与计数门槛。
